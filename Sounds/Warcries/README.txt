ИНСТРУКЦИЯ ПО ДОБАВЛЕНИЮ КАСТОМНЫХ БОЕВЫХ КЛИЧЕЙ (TRIZNOV)
============================================================

В эту папку вы можете положить свои собственные аудиозаписи боевых кличей, криков ликования и звуков строя в формате .wav (PCM 16-bit / 44.1 kHz).

ИМЕНОВАНИЕ ФАЙЛОВ:
------------------
Вы можете называть файлы любым из следующих шаблонов:
1. slava_01.wav, slava_02.wav ... (клики славы и победы)
2. goy_01.wav, goy_02.wav ... (боевой клич "Гой!")
3. warcry_01.wav, warcry_02.wav ... (яростные боевые выкрики)
4. cheer_01.wav, cheer_02.wav ... (общие победные кличи)

КАК ЭТО РАБОТАЕТ В ИГРЕ:
-----------------------
- Когда в этой папке появляются аудиофайлы .wav, мод автоматически находит их при старте игры.
- При выборе ликования/насмешки в радиальном меню (или по клавише клича) мод автоматически глушит стандартный приглушенный голос Bannerlord и воспроизводит случайную запись из этой папки.
- Если папка пуста (или файлов нет), игра использует стандартные голоса по умолчанию без ошибок.
